| 指标 | 值 |

| 每家医院 ΔAUROC（+84a − static）中位数 [IQR] | +0.119 [+0.082, +0.161] |

| 异质性 | τ² = 0.0011，Q = 83.5（df = 56），**I² = 33%** |
| 95% 预测区间 | **[+0.052, +0.184]**（整体在 0 以上） |

医院级用 AUROC 而非 AUPRC：各医院死亡率不同，AUPRC 跨医院不可比。

## 4. 解读

1. **词典的零样本增量在每个分层都成立**：12 个分层的 ΔAUPRC 95% CI 全部不含 0，AUROC 增量 +0.10 至 +0.18。在医院级，57 家中 56 家为正，合并增量 +0.118，异质性中低（I² = 33%），且 95% 预测区间整体在 0 以上：可以预期一家新医院也会获益。
2. **分布层（L1）基本稳定**：JSD 0.105–0.207、ρ 0.82–0.93。唯一越过 0.20 线的是 <100 床（n=748，抽样噪声最大）。
3. **关联层（L2）的同号数稳定（54–67/84），Bonferroni 复现数随样本量下降**（小分层 15–18/34）。这是功效问题：同号比例并未下降，只是小样本里 CI 变宽。不能把小分层的复现数解读为"迁移变差"。
4. **retention 跨分层不可直接比较**：它随分层死亡率升降（South 死亡率 0.171、retention 0.951；Midwest 0.132、0.746），反映的是 AUPRC 对患病率的依赖，而不是迁移程度不同。跨分层比较以 AUROC 增量和医院级合并结果为准。

## 6. 限制

- 描述性、事后（round-3）；12 个分层未做多重比较校正（所有 CI 均远离 0，校正不改变结论）。
- 医院级只纳入 57 家样本充足的医院（覆盖 74% 的 stays）；小医院的增量估计不稳定，未纳入合并。
