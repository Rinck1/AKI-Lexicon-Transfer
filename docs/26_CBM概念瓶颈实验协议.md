# 26 — CBM 概念瓶颈实验协议（方法升级 Phase A · 最小可行）

> **性质**：`docs/25` 方法升级方案的 **Phase A** 落地协议。是「怎么做」的可执行规范，不是已跑完的结论。
> **日期**：2026-08-27。
> **一句话**：把已冻结的 **84 可命名形态概念（连续激活 a）+ 11 检验升降** 做成概念瓶颈层，训练「概念 → 死亡」单一模型，证明预测与解释是同一个模型、支持概念级干预；**评估只用 train 五折，不碰 val / holdout**。

---

## 1. 要回答的科学问题

论文最致命的软肋（`docs/25` §0）是：**预测最好的模型（B）和解释最好的模型（路径 logistic）不是同一个**，且解释单位退化为 0/1 指示符。Phase A 只攻这一个点：

> **Q1（预测=解释）**：死亡 logit 只经过 84 个可命名概念 + 11 检验升降时，train 五折 AUPRC 相对「静态 only」和「静态 + 84 节点 0/1」能保留多少？损失是否可接受？
>
> **Q2（连续 vs 0/1）**：用连续激活强度 a（而非「是否出现」）做概念值，是否比 0/1 指示符多携带可解释信号？
>
> **Q3（可干预）**：训练后能否做**概念级干预**（编辑某概念值 → 看死亡概率变化），且方向与临床一致（乳酸升=危、尿量恢复=护）？

这是 CBM（`2007.04612`）的标准立场，结合临床先验注入（`2407.06600`）。**不做**连续时间点过程（Phase B）、不做影响传播图（Phase C）——那些留到 Phase A 成立之后。

## 3. 概念瓶颈层定义

### 3.1 概念集合（全部人类可读，来自冻结资产）

**A. 84 形态概念**（`events_final_7var_motif84`）
- 身份：`var|家族|B#`，例如 `mbp|缓降持平型|B3`。
- 值：连续激活强度 `a ∈ [0.5, 1]`（winner，`a ≥ 0.5`）；该 stay 无此节点时 = 0。
- 来源：`activations_long.parquet`（字段 `a`、`activation_name`、`stage`）。
- 语义：**多强地**出现该形态-阶段，而非「是否出现」。

**B. 87 检验概念**（`lab_atoms.parquet`）
- 身份：`var|B#|升/降`，例如 `lactate|B3|升高`。
- 值：指示符，出现 = 1，未测/未达阈值 = 0。方向由 `direction` 字段给出（升/降是**两个不同概念**，不是 ±1）。
- 语义：该检验在该阶段的**方向性偏离**（train 阈值冻结于 `lab_thresholds.json`）。

**C. 静态上下文**（非概念、但保留在模型里，见 §3.2）
- 11 列：`AGE, GENDER_M, onset_stage, onset_hour_from_icu, CHF, Diabetes, HTN, CKD_FLAG, COPD, LiverDisease, Arrhythmia`。

### 3.2 模型（线性可加，天然可分解）

```
logit = β0 + Σ β_s · static_s + Σ_{c∈84} β_c · a_c + Σ_{l∈87} γ_l · 1[l 出现]
p = σ(logit)
```

- **线性**（sklearn `LogisticRegression`），每概念一个系数，**系数即解释**。
- 静态是「上下文」，不是瓶颈概念；但它与概念一起进同一个可加模型，预测分数仍可逐项分解。
- 与 B 臂的区别：B 用 252 碎节点 + 308 稠密稀疏 + MLP；CBM 用 84 可命名 + 87 方向 + 线性。前者不可读、后者可读。

### 3.3 可干预性协议（Q3 的核心新增）

训练后，对 val/train 样本做**概念干预**：

1. **单概念置零**：把某患者的概念值置 0（如 `lactate|B3|升高` 1→0；或 `urine_output_ml|低位缓升型|B3` 的 a 0.8→0），重算 p，记 Δp。
2. **群体平均**：对所有**有该概念**的患者做同样干预，取平均 Δp，作为该概念的「风险贡献」。
3. **临床一致性检查**：高危概念（乳酸升、肌酐升、尿量不恢复）应 Δp > 0（置零后死亡概率下降）；保护概念应 Δp < 0。

这一步是 CBM 相对「GNN 节点删除」和「0/1 指示符」的质变：**能减弱、能翻转，而非只能删除**。

## 5. 评估协议（train 五折，与路径口径对齐）

1. **五折**：SUBJECT 分层 5 折（复用 `PATH_SEED=42`），每折在 train 部分 fit、在 val 部分预测。
2. **对照**（同一五折、同一指标）：
   - 静态 only
   - 静态 + 84 节点 0/1（复现 `node_bag` 逻辑，但用五折口径）
   - 静态 + 84 概念连续 a（CBM-a）
   - 静态 + 84 概念 a + 87 检验升降（CBM-a+lab）
3. **指标**：AUPRC（主）、AUROC、Brier（次）。
4. **可干预性**：在训练好的一折模型上，对 train 折内有该概念的患者做置零干预，报告每个概念的群体平均 Δp 与 top/bottom 排名。
5. **系数可读性**：合并五折的系数（或取全 train 拟合一次），按 β 排序，检查方向与临床一致性。

## 6. 判定标准（先写死，避免事后改口径）

| 结论 | 判据 |
|------|------|
| **阳性（预测=解释成立）** | CBM-a+lab 五折 AUPRC ≥ 静态+84 节点 0/1（≥ 0.328 量级），且 ≥ 3 个高危概念 Δp 方向与临床一致 |
| **中性（信息瓶颈可接受）** | CBM-a+lab 五折 AUPRC 低于 0/1 基线，但概念系数方向与临床一致、可干预性方向正确 |
| **阴性（连续 a 无增益）** | CBM-a 不优于 0/1 基线，且干预方向混乱 |

**任何结果都可写**：阳性 → 支持「把概念瓶颈作为预测臂」；中性/阴性 → 支持「本任务上 0/1 指示符已足够，解释单位确为『是否出现』」，这也是结论（与 `docs/22` §2.3「风险原子是节点」呼应）。

## 8. 风险与诚实评估

1. **84 概念 a 值信息量有限**：winner 已 a≥0.5，84 维中每 stay 最多 28 非零、实际更少；连续 a 相对 0/1 的增益可能很小（Q2 可能是阴性）。
2. **线性瓶颈可能弱于 B**：B 的 0.582 有 308 稠密 + MLP 非线性；CBM 的线性可读瓶颈大概率达不到，这是**预期内**的，不追求。
3. **干预 ≠ 因果**：置零干预是 CBM 的关联性协议，不是反事实因果。论文里明说「concept-level intervention（关联）」，不声称因果。
4. **多重比较**：87+84 个系数做「临床一致性」，需用 Bonferroni 或仅报告方向性描述，不进显著性竞赛。

## 11. Phase A 实验结果（已执行，2026-08-27）

> 由 `scripts/47_concept_bottleneck.py --train` 产出，冻结资产哈希见 `data/processed/cbm/cbm_phase_a/cbm_train_cv.json`。

### 11.1 train 五折 AUPRC 对照（`StratifiedGroupKFold`，SUBJECT 分层，seed 42）

| 臂 | AUPRC | AUROC | Brier |
|----|------:|------:|------:|
| 静态 only | 0.249 | 0.662 | 0.119 |
| 静态 + 84 节点 0/1 | 0.351 | 0.759 | 0.110 |
| 静态 + 84 概念连续 a（CBM-a） | 0.360 | 0.765 | 0.110 |
| **静态 + 84 概念 a + 87 检验（CBM-a+lab）** | **0.439** | **0.811** | **0.103** |

- 静态 only 0.249 与 `docs/22` §7.3 的 train 五折 0.249 **完全一致**，口径校验通过。
- 参照：15 条路径 logistic 的 train 五折为 0.386（`docs/22` §7.3）。

### 11.2 三个科学问题的答案

- **Q1（预测=解释）**：**成立**。CBM-a+lab 五折 0.439 ≥ 0/1 基线 0.351，且是**单一可干预模型**——死亡 logit 只经过 84 可命名概念 + 87 检验升降。
- **Q2（连续 vs 0/1）**：**弱增益**。连续 a（0.360）仅略高于 0/1（0.351，+0.009），与 §8 风险 1 预判一致；主要增益来自加入 87 检验升降（+0.088）。
- **Q3（可干预）**：**方向高度临床一致**（远超「≥3 个高危概念方向一致」的判据）：

| 概念 | 干预 Δp | 临床解读 |
|------|------:|----------|
| `lactate|B4|升高` | +0.133 | 晚期乳酸升 = 危 ✓ |
| `gcs_total|B1|下降` | +0.120 | 早期神志变差 = 危 ✓ |
| `lactate|B3|升高` | +0.083 | 乳酸 B3 升 = 危 ✓ |
| `gcs_total|B4|下降` | +0.079 | 晚期神志变差 = 危 ✓ |
| `gcs_total|B2|升高` | −0.110 | 神志改善 = 护 ✓ |
| `creatinine|B3|下降` | −0.047 | 肾功恢复 = 护 ✓ |

### 11.3 诚实边界（写论文时必须写）

1. 这是 **train 五折**，未用 val / holdout（val 已锁 `once`）。0.439 相对 val 口径偏乐观，不可与 val 0.349 直接对比。
2. CBM 用 171 个概念 vs 路径 15 条，自由度差异大，不能直接说「CBM 更好」。
3. 干预是 **关联性**（置零 → Δp），不是反事实因果。
4. CBM 的 AUPRC 0.439 仍低于预测参照 B（val 0.582），符合「解释优先、不刷分」的项目立场。

### 11.4 与冻结 15 条路径的关系（2026-08-27 锁定）

完整三层结论见 `docs/27_可解释性三层_路径冻结与CBM.md`。此处只钉三条：

1. **不重选路径。** CBM 不挖 2-step，不按 \(\Delta p\) 改 `path_set_selected.json`。
2. **0.439 不是更好的路径。** 171 个单概念 vs 15 条 2-step；连续 \(a\) 相对 0/1 仅 +0.009。
3. **Δp 是阳性子集上的置零干预**，不是全队列平均，不是翻转反概念，不是因果。高危端点（乳酸↑、GCS↓、尿量低位）与冻结路径端点重合，用作确认。

`urine_output_ml|低位波动型|B1` 在 CBM 偏保护，却是路径 8、11 的起点：单概念看不清「接着变差」，这正是路径不可被 CBM 替代的理由。
