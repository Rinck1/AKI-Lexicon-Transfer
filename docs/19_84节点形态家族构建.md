1. 线性重采样到 12 点；
2. 形态标准化：`(template − template[0]) / peak-to-peak`；幅度接近 0 则保持平移后的零序列；
3. 原始幅度（start / end / range）只作描述，不参与匹配；
4. L=6 的 k=0/1/2 **原样成为** family 0/1/2（锚点永不标低置信）；
5. L=4 与 L=12 的每个模板**独立**选 `argmin_f cost(template, anchor_f)`。允许同一长度多个模板进同一家族，也允许某长度某家族为空。

## 3. 临床命名（先看曲线，再写标签）

命名依据是 **L=6 锚点曲线 + 家族成员平均形态**，不是预先规定的“升 / 降 / 平”，也不是 val 死亡率。

| 变量 | f0 | f1 | f2 |
|------|----|----|----|
| heart_rate | 高峰回落型 | 低位回升型 | 持续上升型 |
| sbp | 低位下滑型 | 大幅波动型 | 恢复上升型 |
| dbp | 后期下降型 | 持续下降型 | 低位回升型 |
| mbp | 回落反跳型 | 缓降持平型 | 恢复上升型 |
| respiratory_rate | 低谷回升型 | 波动上升型 | 末期骤降型 |
| spo2 | 大幅振荡型 | 低位波动型 | 高位回落型 |
| urine_output_ml | 进行性下降型 | 低位波动型 | 低位缓升型 |

命名要点（锚点形态）：

- **mbp-f0 回落反跳型**：先降后在末端拉回，不是单调下降。
- **mbp-f1 缓降持平型**：L6 锚点处于极低平台、略下滑；同族 L4 可以是高位近平台——形态相近、绝对水平不同，幅度留给节点特征。
- **urine-f0 进行性下降型**：由相对高位坠入低尿量，不是“低位波动”。
- **spo2-f0 大幅振荡型**：高位大幅来回，不是单纯下降。
- **rr-f2 末期骤降型**：中段尚可、末端骤降，与“低谷回升”分开。

节点身份仍用临床标签：`{var}|{临床标签}|{stage}`。  
低置信事件的患者级展示改为：`{var}|f{family}（低置信跨尺度映射）|{stage}`。

| 训练 mean(g) @ best | — | **0.218** |
| val 门控范围 | — | [0.11, 0.30]，无边 g>0.5 |
| 有效边数 \((\sum g)^2/\sum g^2\) | ~62（均匀） | **66.6 ≈ E** |

预测略好于 84 additive，也略高于 252 additive（0.313）。节点忠实度更强。  
**但门控没有完成选择**：所有边的 \(g_e\) 挤在 0.16–0.24，\(L_{sparse}\) 只是把全局平均压低，没有出现“少数边重要、其余接近 0”。因此归一化熵升到 0.997，边删除相对随机仍不显著。

结论：84 节点图包与独立最近锚点映射保持冻结。

门控的失败是**公式退化解**，不是 \(\lambda_s\) 太小：

- 边贡献为 \(E^{-1/2}\sum_e g_e v_e\)。若所有 \(g_e\leftarrow \alpha g_e\)，\(v_e\leftarrow v_e/\alpha\)，则 BCE 项不变，而 \(L_{\mathrm{sparse}}=\mathrm{mean}(g_e)\) 随 \(\alpha\) 下降。因此梯度只会把全体门控一起压低。
- 实测 val 上门控落在 \([0.11,0.30]\)，没有任何 \(g>0.5\)；有效边数 \(\approx E\)。这正是“常数门控 + value 吸收尺度”的解，不是“少数边打开”。
- 加大 \(\lambda_s\) 只会把这个常数从 0.22 压到更低，value 再放大补偿，归一化熵仍接近 1。

下一步若改读出，必须打破“全体乘同一系数”的自由度（竞争 / 允许精确 0 / 惩罚有效边数），而不是加大 \(\lambda_s\)。不改节点字典，不加第三层，不加 308 维。

解释产物：`outputs/reports/18_GNN可解释性验证_additive_gate_G_motif84.md`。

`additive_gate` 保留为：

> 84 节点最佳连续边读出模型，AUPRC 0.322，节点解释增强，但连续门控发生常数塌缩。

## 6.3 统一硬边掩码（additive_l0）

保持冻结：独立最近锚点映射、84 节点字典、两层、L/12、事件与边词表、节点可分解读出、seed=42、lr=2e-4、batch=16、test 锁定。只改边选择：

- 同一 \(z_e\) 同时乘到两层消息和边直接贡献 \(c_e=z_e v_e\)
- Hard-Concrete / L0：\(\log\alpha_e=\alpha_{\text{edge type}}+\delta_{\text{patient}}(h_0)\)
- \(v_e=v_{\max}\tanh(\mathrm{MLP}(e))\)，\(v_{\max}=2\)
- \(L=\mathrm{BCE}+\lambda_{L0}\overline{\pi}+\lambda_{\mathrm{rank}}(1-\mathrm{corr}(\pi^{(1)},\pi^{(2)}))\)，\(\lambda_{L0}=0.05\)，\(\lambda_{\mathrm{rank}}=0.02\)（冻结，未搜索）
- 推理用硬 0/1；删除验证按选择概率 \(\pi\) 排序

| 项 | 84 additive_gate | 84 additive_l0 |
|----|------------------|----------------|
| best epoch | 7 | **34** |
| val AUPRC | 0.3220 | **0.3464** |
| val AUROC | 0.7550 | **0.7689** |
| val Brier | 0.2031 | **0.1782** |
| 节点 AUPRC(random−top) | 0.082 [0.054, 0.113] | **0.073 [0.040, 0.115]** |
| 边 AUPRC(random−top) | −0.003 跨 0 | **0.0015 [−0.005, 0.008] 仍跨 0** |
| 边 top−random \|Δlogit\| | 弱 | **0.095 [0.087, 0.102]（logit 层显著）** |
| 边归一化熵 | 0.997 | **0.185** |
| 有边患者平均选中边数 | —（连续 g∈[0.11,0.30]） | **0.40（中位数 0）** |
| 有边患者全 0 / 全 1 mask | 无真正 0/1 | **69.8% / 0%** |
| 边 top Jaccard（固定拓扑抖动） | 高（全体相近） | **0.983** |

定性：

> 84节点Hard-Concrete模型取得目前图模型中最佳预测性能（AUPRC 0.346），但性能主要来源于节点和静态分支。离散边选择高度稀疏，且选中边删除未显著降低群体AUPRC，因此尚未证明稳定关键边的存在。

该 checkpoint 保留为 **84 节点最佳图预测模型**（AUPRC 0.346 / AUROC 0.769 / Brier 0.178），**不能作为关键边解释模型**。

两个指标不得过度解读：

- 边 Jaccard 0.983 来自按 \(\pi\) 取 top-20%，不是 hard mask；大量患者两次扰动的 hard 选择都是空集。空∩空被计为稳定会夸大一致性，应只在“原始选择非空”的患者上报告 Jaccard。
- 支持数 ≥20 的群体边只有 15 条，其中 9 条方向一致，只作描述，不能当成稳定关键边清单。

允许模型不选边时，它几乎不选：节点+静态已经能预测，边增量有限，\(L_{L0}\) 又要求越少越好。再加大 L0 只会更空，不会产生稳定关键边。

成功标准对照：

1. AUPRC 不低于 0.322：**通过**（0.346）。
2. hard mask 不是全 0 或全 1：**仅在语料级通过**。模型并非全局全 0，但 **69.8%** 有边患者一张边都没选中；中位数为 0。
3. 选中边数明显低于约 68：**通过，但过稀**（0.40）。
4. 按 \(\pi\) 删除 top 边的 AUPRC 影响显著大于随机边：**未通过**（CI 跨 0）。绝对 logit 变化大于随机，但不足以移动 AUPRC。原因：top-20% 仍是约 14 条边，其中绝大多数 \(z=0\)，真正打开的平均不到 1 条。
5. 轻微激活/时间扰动下选择稳定：**通过**（边 Jaccard 0.983）。
6. 群体关键边风险方向相对一致：**部分通过**。n≥20 的 15 条群体选中边中 9 条（60%）患者间符号完全一致；主选边 `mbp|缓降持平型|B3 → RR|低谷回升型|B3`（CO_OCCUR，99 人，全正）和 `RR|低谷回升型|B1 → sbp|恢复上升型|B2`（83 人，全正）方向稳定。`spo2|大幅振荡型|B2 → RR|低谷回升型|B3`（95 人）53 正 / 42 负，方向不稳。
7. 低置信形态边不异常富集：**通过**。全体边 23.0% 至少一端低置信；选中边 10.4%；π-top20% 18.9%。未富集。

解释：Hard-Concrete 打破了“全体 \(g\) 乘同一系数”的尺度退化——熵从 0.997 降到 0.185，推理得到真正的 0/1，\(v\) 被 \(\tanh\) 限制在 \([-2,2]\)。但 \(\lambda_{L0}=0.05\) 加上硬阈值（\(\pi\lesssim 0.31\) 时 eval 仍为 0）把解推到了**另一个退化点**：几乎关掉所有边，预测主要靠节点读出 + 静态。AUPRC 提高来自节点/静态，不是来自可用的边选择。加大 \(\lambda_{L0}\) 会更空；这里已经过空，下一步也不是再加大稀疏系数。

若要得到“每人约十余条、可删边验证”的选择，需要改的是**选择目标本身**（例如对期望选中数做锚定，或只在已选集合上做删除），而不是节点字典、层数或 308 维。本轮不搜索这些超参。

## 6.4 固定预算 straight-through top-k（最后一次边选择诊断）

不再学习“要不要选边”，只学习：在必须保留 \(K_i=\max(1,\lceil 0.2 E_i\rceil)\) 条边时，哪些边最值得留。平均约 13.95 条。同一 \(z\) 仍同时控制两层消息和边贡献；\(v=2\tanh(\mathrm{MLP})\)；取消 \(L_{L0}\) 与 \(\pi>0.5\) 阈值。\(s_e\) 是边排序分数，不是概率。稳定性为共同边的 \(1-\mathrm{corr}(s^{(1)},s^{(2)})\)。删除在选择完成之后进行，对照匹配随机边（同患者、同边数、同类型比、尽量匹配阶段与低置信端点）。K=20% 沿用既定删除协议，未搜索。

成功标准：

1. AUPRC 不明显低于 0.346：**未通过**（0.315）。
2. 非空患者扰动 Jaccard 稳定：**通过**（0.985）。
3. 删除选中边相对匹配随机边的 AUPRC 差 95% CI 不跨 0：**未通过**。
4. 群体边方向一致：**未达到可报告的一致性**。n≥20 的 425 条边中仅 53% 患者间符号完全一致；多数选中边的 \(v\) 为负（抑制风险），但不能把它们写成稳定关键死亡边。
5. 低置信形态边不异常富集：**通过**（选中 25.3% vs 全体 23.0%）。

固定预算已经消除了“模型把边全部关掉”的借口。选中边确实更大地改变了局部 logit（绝对 Δlogit 显著大于匹配随机），也略降低了点估计 AUPRC（0.315→0.300 vs 随机 0.313），但群体排序差异的置信区间仍跨 0。强制选边还付出了预测代价（相对 L0 的 0.346）。

**停止边结构优化。** 接受：

> 当前图边可以改善部分患者的局部logit，但在群体死亡排序中没有稳定增量；模型的可靠解释单位是节点，而不是边。

继续修改选择压力只会制造人为关键边，而不是从数据中识别关键边。

若仍要挖「关键临床路径」，定义改为训练期内时间有序、经 bootstrap 稳定、与死亡同号关联的状态轨迹；GNN 只确认节点。协议见 `docs/20_时序路径挖掘协议.md`。
